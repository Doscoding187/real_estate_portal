# Search results card direction v1 prompt

Mode: built-in image generation

Use case: `ui-mockup`

Asset type: product direction / acceptance mockup for a desktop real-estate
search results page.

Input image: the 2026-08-28 local Johannesburg Buy-results screenshot was used
as a style and product-context reference only. The generated output is a new
interface, not an edit of the screenshot.

Primary request: Create a polished, shippable desktop web UI mockup for
Property Listify showing residential properties for sale in Johannesburg.
Focus on a refined, compact result-card system that helps buyers scan and
compare quickly while preserving clear source identity and trust.

Style and composition: realistic modern SaaS product UI with crisp typography,
practical spacing, a compact blue header, restrained title/count row, active
filter chips, slim filter rail, and a wide result column. Show two complete
horizontal cards and the start of a third. Each card uses a wide property photo
and a compact content panel.

Card hierarchy: price; title; canonical suburb, city and province; four typed
facts; one short value proposition; verified lister identity; photo count,
save and compare controls. The whole card is the main navigation target, with
a quiet “View property” affordance rather than a large contact button. Reserve
orange for conversion accents and use it sparingly.

Required example copy included Property Listify, Johannesburg Buy-result
headings, South African Rand prices, residential facts, verified-agent identity,
save/compare controls and recommended sorting.

Palette and constraints: preserve Property Listify royal blue and deep navy,
white and cool-grey surfaces, subtle slate borders and minimal warm orange.
Use accessible contrast, a consistent spacing rhythm and realistic controls.
Avoid unrelated logos, watermarks, competitor branding, decorative gradients,
glassmorphism and oversized rounded containers.
