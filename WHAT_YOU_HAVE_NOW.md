## 🚀 How to See It

### Step 1: Start Server
```bash
npm run dev
```

### Step 2: Open Browser
```
http://localhost:8081/explore
```

### Step 3: Explore!
- Click **Home/Cards/Videos** to switch views
- Try the **filters** (bottom-right button)
- Select **lifestyle categories** (Family, Luxury, etc.)
- Click on **properties** to see details
