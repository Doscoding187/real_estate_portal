## Purpose

Audit the complete agent product from the agent's perspective across the
journey spine Discover → Understand → Consider → Convert → Onboard → Activate →
Operate → Get discovered → Receive leads → See value → Return → Grow, governed
by the question:

> What must be true for the Agent Product to be genuinely worth paying for and
> worth continuing to use?
