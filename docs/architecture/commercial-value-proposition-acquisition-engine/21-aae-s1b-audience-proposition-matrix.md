# AAE-S1B — Audience Proposition Matrix

| Field | Value |
| --- | --- |
| Status | Founder-approved AAE-S1B internal audience-proposition architecture; not public copy, commercial availability or a pricing decision |
| Relationship | Amends the AAE-S0 audience structure by adding private property owners/direct listers and individual/portfolio property investors; applies existing S1A evidence only through qualified reuse and does not amend or supersede S1A. |
| Reading rule | “Current support” means delivered or qualified S1A evidence only. Exploratory directions are not current value; commercial motions are hypotheses for later authority. Audience problem statements are strategic hypotheses derived from AAE-S0 and must not be presented as measured customer prevalence without separate customer evidence. |

## Consumers and property seekers

| Field | Internal architecture |
| --- | --- |
| Definition / primary job | People seeking property information who need to discover opportunities, assess available context and progress interest. |
| Strategic problem hypothesis / desired outcome | Fragmented discovery and uncertain next steps / find relevant available information and reach an appropriate supported recipient. |
| Internal proposition | Property Listify is designed to help property seekers discover available opportunities, understand the information provided and move from interest to an appropriate enquiry or next-step request. |
| Traceability | `CON-PROP-01`–`CON-PROP-04` |
| Discovery / Trust / Operations / Progression | Search, detail, suburb insight and Explore / qualified available information, not verification / consumers do not operate a commercial workspace / saved searches, favourites, enquiries, viewing requests, affordability guidance and recipient handoff where supported. |
| Current support | Delivered: `CON-07`. Qualified: `CON-01`–`CON-06`, `CON-08`–`CON-10`; demonstrations `PRF-21`, `PRF-22`. |
| Exploratory / limitations / prohibited | No consumer future feature is proposed here / coverage, freshness, personalisation, response, viewing confirmation and finance result are qualified / no complete-market, verified-listing, instant-booking, bond-approval or guaranteed-response claims. |
| Commercial motion / conversion objective | Not a paid-audience motion / progress a supported enquiry or next-step request, not a monetised conversion. |
| Later-authority decisions | Handoff governance, data methodology, consent, availability of recipient programmes and experience contract. |

## Private property owners and direct listers

| Field | Internal architecture |
| --- | --- |
| Definition / primary job | Individuals directly presenting a property they own or are authorised to list for sale, rental or shared-living participation. |
| Strategic problem hypothesis / desired outcome | Direct listers may lack a coherent path from property preparation and presentation to supported buyer or tenant follow-up / present an opportunity responsibly and progress suitable interest without requiring an agency-operated listing. |
| Internal proposition | Property Listify is designed to help private property owners prepare and present a sale, rental or shared-living opportunity, organise supported buyer or tenant interest, and progress an appropriate next step. |
| Traceability | `OWN-PROP-01`–`OWN-PROP-04` |
| Discovery / Trust / Operations / Progression | Property presentation and discovery where separately authorised / ownership, representation and disclosure context require governance / authenticated listing creation, editing, submission and status foundations are reusable / enquiry, viewing and assisted handoff foundations may support progression. |
| Current support | Qualified reuse of existing S1A listing and enquiry foundations, corroborated by private-seller presentation states, user-owned listing creation, review/publication workflow, seller planning and agent-assisted seller-prospect handoff. This does not establish owner-specific availability. |
| Exploratory / limitations / prohibited | A dedicated owner role/workspace, ownership verification, disclosure authority, direct-publication entitlement, commercial package and complete self-service journey are not established / no verified-owner, guaranteed-enquiry, guaranteed-sale, guaranteed-tenant, legal-compliance or transaction-completion claim. |
| Commercial motion / conversion objective | Direct self-service, paid listing, assisted listing and owner-to-agent handoff remain commercial hypotheses / later authority must define which motion is permitted. |
| Future authority decisions | Identity and ownership authority, listing rights, moderation, disclosures, eligibility, entitlement, pricing, support model, route and post-enquiry operating responsibility. |

## Individual and portfolio property investors

| Field | Internal architecture |
| --- | --- |
| Definition / primary job | Individuals or portfolio owners evaluating, acquiring, operating, refinancing or exiting property investments. |
| Strategic problem hypothesis / desired outcome | Investment discovery, affordability context and later ownership work may be fragmented / evaluate relevant opportunities and organise the information and next steps needed for an appropriate property-investment decision. |
| Internal proposition | Property Listify is designed to help individual and portfolio investors discover property opportunities, organise supported property and affordability information, and progress appropriate acquisition, ownership or exit decisions. |
| Traceability | `INV-PROP-01`–`INV-PROP-04` |
| Discovery / Trust / Operations / Progression | Search, location, development and Explore foundations / qualified property and finance context, not investment advice or verified returns / saved-property, affordability and referral foundations, but no investor portfolio operating system / enquiry, viewing, referral, offer and transaction foundations may support acquisition or exit progression. |
| Current support | Qualified reuse of existing consumer discovery, saved-property, affordability, referral, viewing, offer and transaction foundations; investor intent is represented in selected buyer/referral contexts. |
| Exploratory / limitations / prohibited | No canonical investor role, investor workspace, property-ownership graph, yield model, valuation authority, portfolio-management engine, rental-operation engine, rent collection, occupancy, expense or maintenance authority is established / no return, appreciation, yield, valuation, guaranteed-tenant or financial-advice claim. |
| Commercial motion / conversion objective | Consumer discovery, assisted referral, strategic partnership and a future investor or portfolio product remain distinct hypotheses / no current investor package or subscription is authorised. |
| Future authority decisions | Investor segmentation, data methodology, regulated advice boundary, acquisition versus ownership scope, portfolio authority, financial calculations, commercial model, partner participation, routes and evidence ownership. |

| Internal proposition | Property Listify is designed to help individual agents present property opportunities, receive supported enquiries and organise listing, lead, viewing, mandate and deal work in one agent-facing context. |
| Traceability | `AGT-PROP-01`–`AGT-PROP-04` |
| Discovery / Trust / Operations / Progression | Eligible publication and media / profile foundation, not professional verification / listing, performance, qualification, assignment, canvassing, mandate and entitlement foundations / enquiry capture, viewing, offer and transaction foundations. |

| Exploratory / limitations / prohibited | Paid visibility `AGT-16` is exploratory / plans, publication eligibility, verification, CRM, quantity, quality, exclusivity, performance and response remain unresolved or prohibited / no verified professional, qualified lead, CRM integration, ROI, free-trial, pricing or guaranteed-mandate claim. |
| Commercial motion / conversion objective | Subscription or early-access package is a hypothesis only / later S1C must define whether a qualified professional can enter a governed activation path. |
| Later-authority decisions | Self-service versus assisted motion, eligibility, plan/entitlement authority, onboarding destination, price/offer, proof and route experience. |
