Required and optional information. Account, ownership, enquiry and billing fields identified as required are needed to provide the relevant function. Agreement to our Terms or acknowledgement of this notice is not a blanket permission for every international transfer or other processing activity.

Cookies and browser storage. We use a sign-in cookie for account authentication, restricted from JavaScript access and transmitted securely on the hosted service. The browser may also keep property-comparison preferences, searches, recently viewed and favourite property identifiers, interface preferences, account return state and private listing or organisation workflow drafts. Browser-local preferences and some drafts have no automatic time-based expiry. Session storage ordinarily lasts for the browser tab's session; browser session restoration can preserve it. Server-side records are separate.

Storage choices and shared devices. You can clear this site's stored data through your browser settings. This may remove preferences, return state and unsaved drafts. Signing out does not guarantee that every local preference or draft is removed. Avoid preparing confidential drafts on a shared device, and clear site data when necessary. Guest activity can be transferred into your account through the relevant account workflow; local transferable activity is cleared only after a successful transfer.

Advertise interaction events. The Advertise page creates a browser-session identifier and attempts to send page views, scroll-depth and interaction events to the site's analytics endpoint. Event metadata can include device type, a session identifier, an available local user identifier and referral information. The application endpoint logs selected event fields in operational logs; it does not implement a separate analytics database store. The browser can also send events to Google Analytics if that integration has been loaded. A send attempt does not establish successful receipt. Provider-side log retention is separate from browser-session storage. Clearing browser storage does not remove an event already received in a log.
