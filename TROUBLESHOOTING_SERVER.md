# Server Troubleshooting

> **Historical troubleshooting guide retired.** Its environment examples,
> direct database checks, package mutation commands, process-killing commands,
> and manual setup instructions are not current authority. Git history retains
> the former guide.

For current diagnosis:

- use the repository-declared package scripts and supported diagnostics;
- use the Database Authority entry contract for local database status and
  lifecycle decisions;
- use the current environment authority without printing or reconstructing
  credentials; and
- treat application logs, type-check output, tests, and CI as the evidence for
  runtime failures.

This document makes no claim that the application is production-ready.
