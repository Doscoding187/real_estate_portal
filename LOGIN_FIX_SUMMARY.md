# Retired ad-hoc account administration utilities

This historical note is retained only to explain why the former account
bootstrap and password-repair utilities are absent. They are prohibited and
must not be recreated as operator commands.

Account recovery is not a repository seed or repair authority. Use the
approved application flow or a separately approved break-glass operating
contract. Local demo accounts are created only through the canonical guarded
local/test lifecycle.

For database authority, use `server/migrations/README.md`,
`docs/database-authority/database-change-protocol.md`, and
`docs/database-authority/00-database-authority-agent-entry.md`.
